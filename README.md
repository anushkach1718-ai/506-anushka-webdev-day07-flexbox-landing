# 🌿 Fieldnotes – Flexbox Landing Page

A beautiful and responsive outdoor-gear landing page developed as part of the **Day 7 / Week 7 Web Development Flexbox Assignment**.

Fieldnotes is designed for outdoor and adventure lovers, featuring a modern pastel colour palette, attractive product cards, membership plans, and a login form.

## ✨ Project Overview

The Fieldnotes landing page showcases outdoor products and adventure essentials through a clean, colourful, and user-friendly interface.

The website uses HTML5 and CSS3, with a special focus on CSS Flexbox concepts and responsive web design.

## 🚀 Features

- Responsive navigation bar.
- Attractive hero section with background imagery.
- Outdoor product cards with images and pricing.
- Flexible product layout using Flexbox.
- Three membership pricing plans.
- Centred login form with basic front-end interaction.
- Beautiful pastel colour theme.
- Hover effects and smooth scrolling.
- Mobile, tablet, and desktop responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- Media Queries
- JavaScript (basic form interaction)
- Unsplash (product and background images)

The website is designed to work across different screen sizes.

## 💻 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. View the website in your browser.

No additional installation or build tools are required.

An internet connection is required to load the Unsplash images.

## 📚 Flexbox Concepts Demonstrated

- `display: flex` – Creates flexible layouts.
- `justify-content` – Aligns and distributes items.
- `align-items` – Controls cross-axis alignment.
- `flex-wrap` – Allows items to move onto new rows.
- `flex-grow` – Allows cards to expand.
- `flex-basis` – Sets the initial size of flex items.
- `flex-direction` – Changes the layout direction.
- `gap` – Adds spacing between flex items.
